# shoot-a-plinko
This is a game made by Leo Quan, Eldridge Huang, and Arjun Krishnan. All art is by Arjun and game concept by
whole team. 

Press and hold space to increase the amount of power on the ball that will try to go into the plinko board. You get prizes
from getting to the bottom while getting items on the way down.

Install the game on your phone by going into horizontal view -> share -> scroll down all the way -> show page on homescreen -> make sure install page as web app is turned on

Music is from www.classicals.de's Korobeiniki
